# Student Dashboard Components

مجموعة مكونات لوحة تحكم الطلاب مع تصميم جميل وحركات سلسة.

## المكونات المتاحة

### 1. EnrollCourse
مكون التسجيل في الكورسات مع عرض جميع الكورسات المتاحة.

**الميزات:**
- عرض الكورسات في شبكة جميلة
- أزرار تسجيل تفاعلية مع أصوات
- حالات تحميل وتأكيد
- تصميم متجاوب

### 2. ViewContent
مكون عرض المحتوى مع أربعة أوضاع مختلفة.

**الأوضاع:**
- الوحدات (Modules)
- الدروس (Lessons)
- Markdown
- الفيديوهات (Videos)

### 3. SelectCompleted
مكون تحديد الدروس المكتملة.

**الميزات:**
- عرض جميع الدروس
- تحديد الدروس كمكتملة
- تأكيدات بصرية وصوتية

### 4. CompletedLessons
مكون عرض الدروس المكتملة مع احتفالات.

**الميزات:**
- عداد الدروس المكتملة
- رسوم متحركة احتفالية
- حالة فارغة محفزة

## الاستخدام

```tsx
import { StudentDashboard } from './pages/student/StudentDashboard';

function App() {
  return <StudentDashboard />;
}
```

## التصميم والألوان

### نظام الألوان
- **أخضر**: التسجيل في الكورسات (#10b981 - #34d399)
- **أزرق**: عرض المحتوى (#3b82f6 - #60a5fa)
- **بنفسجي**: الدروس المكتملة (#8b5cf6 - #a78bfa)
- **برتقالي**: تحديد الإكمال (#f59e0b - #fbbf24)

### الحركات
- `fadeInUp`: دخول العناصر من الأسفل
- `bounce`: حركة القفز للأيقونات
- `pulse`: نبضات للعناصر النشطة
- `float`: طفو للعلامات المائية
- `rotate`: دوران للـ spinners

## المتطلبات

### الخدمات المطلوبة
- `CourseService`: للحصول على الكورسات
- `StudentService`: لعمليات الطلاب
- `ModuleService`: للحصول على الوحدات
- `LessonService`: للحصول على الدروس

### المكونات المطلوبة
- `MarkdownViewer`: لعرض محتوى Markdown
- `VideoViewer`: لتشغيل الفيديوهات

## الاستجابة (Responsive)

التصميم متجاوب بالكامل مع نقاط التوقف:
- **Desktop**: 1024px+
- **Tablet**: 768px - 1024px
- **Mobile**: أقل من 768px
